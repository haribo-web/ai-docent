# AI 도슨트 (큐레이터즈)

국립민속박물관 상설전시관 3 《한국인의 일생》을 위한 **AI 기반 문화복지 도슨트 웹 서비스**입니다.

앱 설치나 복잡한 QR 오디오 가이드 사용을 어려워하는 관람객도 쉽게 쓸 수 있도록 만듭니다.
관람객은 지금 보고 있는 작품을 **작품 설명판의 이름**이나 **전시 구역**으로 찾은 뒤 다음 기능을 쓸 수 있습니다.
위치정보와 회원가입 없이 이용합니다.

- 수준에 맞춘 설명(쉬운 설명 / 자세한 설명) 보기
- 설명을 소리로 듣기
- AI 도슨트에게 질문하기

## 실행 방법

Node.js 20.10 이상이 필요합니다. 처음 한 번은 패키지를 설치하세요.

```bash
npm install
```

```bash
npm run dev
```

AI 답변을 켜려면 `.env.example`을 복사해 `.env`를 만들고 `GROQ_API_KEY`를 넣은 뒤 서버를 다시 시작하세요.
키가 없으면 AI 대신 "준비 중" 답변이 나옵니다. `api/_lib/`의 파일을 고친 뒤에도 서버를 다시 시작해야 반영됩니다.

AI 답변을 한꺼번에 시험하려면, 개발 서버를 켜 둔 채로 다른 터미널에서 아래를 실행하세요. (질문 목록: `scripts/try-questions.js`)

```bash
npm run try:ai
```

브라우저에서 http://localhost:3000 을 엽니다.

## 전시물 데이터

전시물 정보는 팀이 함께 정리한 엑셀 **`작품 정리_정리본.xlsx`**가 원본입니다.
`public/data/exhibits.json`은 이 엑셀에서 자동으로 만들어지므로 **직접 고치지 않습니다.**

엑셀을 고친 뒤에는 아래 명령으로 JSON을 다시 만드세요.

```bash
npm run build:data
```

- 데이터 형식과 설명을 만드는 방법은 `docs/전시데이터_설명기능.md`(1번 담당)를 보세요.

### 작품 식별 방식 (팀 최종 결정)

- **관람객은 작품명으로 작품을 찾고 고릅니다.** (이름 검색, 지도 핀, 작품 목록) 작품 번호(101 등)는 쓰지 않습니다.
- 화면과 AI는 작품마다 고정된 **고유 ID**로 작품을 연결합니다. 데이터의 `slug` 칸입니다. (예: 감모여재도 → `gammoyeojaedo`, 주소 `exhibit.html?id=gammoyeojaedo`)
  - 고유 ID는 **`data/exhibit-ids.json`에 고정**되어 있어서, 엑셀 행 순서가 바뀌어도 그대로입니다.
  - 엑셀에서 **작품명을 바꾸면 새 ID가 생깁니다.** 예전 ID를 유지하려면 `data/exhibit-ids.json`에서 작품명도 같이 바꿔 주세요.
- 데이터에 남아 있는 옛 번호 칸(`id`의 숫자, `number`)은 화면과 AI에서 쓰지 않습니다.
- 작품 순서(목록, 이전/다음)는 챕터 순서 → 엑셀 행 순서입니다.

## 배포 (Vercel)

1. 이 폴더를 GitHub 저장소에 올립니다.
2. https://vercel.com 에서 GitHub 계정으로 로그인하고 저장소를 Import 합니다.
3. Framework Preset은 **Other**로 두고, 빌드 설정 없이 Deploy를 누릅니다.
4. Settings > Environment Variables에 `GROQ_API_KEY`를 추가합니다.

Vercel은 `public/` 폴더를 웹페이지로, `api/` 폴더를 서버 함수로 자동 인식합니다.

## 화면 구성 

### 1. 첫 화면 (`index.html` + `js/home.js`)

| 영역 | 기능 |
| --- | --- |
| 상단 | 서비스 이름, **글자 크게** 버튼 (선택한 크기 기억) |
| 이름으로 찾기 | 작품 이름(일부만 입력해도 됨) → 하나면 바로 이동, 여러 개면 목록 표시 |
| 전시관 지도 | 전시 구역(1~9부)과 작품 핀(작품 이름 앞 2글자 표시). 핀을 누르면 설명 화면으로 이동 |
| 작품 목록 | 전시관별로 묶은 큰 버튼 목록 (지도의 작은 핀을 누르기 어려운 분용) |

### 2. 전시물 설명 화면 (`exhibit.html` + `js/exhibit.js`)

| 영역 | 기능 |
| --- | --- |
| 작품 정보 | 전시관, 전시 구역, 작품 이름, 시대 |
| 설명 수준 | **쉬운 설명 / 자세한 설명** 탭 전환 (빈 줄로 문단 구분) |
| 소리로 듣기 | 브라우저 내장 음성으로 설명 읽기 (한국어, 조금 느린 속도) |
| AI 도슨트 | 준비된 질문 버튼 3개 + 직접 입력. 대화 형식으로 표시, 답변도 소리로 듣기 가능 |
| 추천 | "이 작품이 좋았다면": 같은 전시관의 다른 작품 최대 3개 |
| 이동 | 처음으로, 이전 작품, 다음 작품 |

### 접근성 원칙

- 기본 글자 19px, 크게 보기 23px
- 버튼 높이 최소 44px 이상
- 키보드로 모든 기능 조작 가능
- 기기 설정에 따라 다크 모드 자동 적용
- 모든 문구는 쉬운 존댓말("~해요")

### 데이터 관련 참고

- `hall` 값(1~9)별로 지도 칸과 목록이 자동으로 만들어집니다.
- 전시 이름은 `public/js/home.js` 맨 위 `HALL_NAMES`에 적으면 지도와 목록에 표시됩니다.
- 설명에 빈 줄을 넣으면 문단이 나뉩니다.

### 화면 ↔ AI 연결 형식

설명 화면은 `POST /api/docent`로 아래 값을 보냅니다.

```json
{ "exhibitId": "gammoyeojaedo", "name": "감모여재도(感慕如在圖)", "level": "easy", "question": "관람객 질문" }
```

- `exhibitId`: 작품 고유 ID. 서버는 이것으로 작품을 찾고, 없으면 `name`(작품 이름)으로 찾습니다.
- `level`: 지금 보고 있는 설명 수준(`easy` 쉬운 / `detail` 자세한). 답변 길이가 달라집니다.

응답은 `{ "answer": "답변 글" }`, 실패 시 `{ "error": "안내 문구" }` 형식으로 받습니다.
형식이 다르면 `public/js/exhibit.js` 맨 위의 **연결 설정**만 고치면 됩니다.
