# 관람 노트 (인상 깊은 작품 · 감상 메모 · AI 감상문 · 공유)

관람객이 인상 깊은 작품을 표시하고 감상을 적어 두면, AI가 한 편의 감상문으로 다듬어 주고
휴대폰 공유 창으로 메모 앱·카카오톡 등에 보낼 수 있습니다.

## 화면 흐름

작품 설명·소리로 듣기가 메인이고, 관람평은 화면 맨 아래 별도 칸에 둡니다.

1. **설명 화면 맨 아래 `✍️ 관람평 남기기`** (추천 작품 다음, 이전/다음 버튼 위): `☆ 인상 깊어요` + "어떠셨어요?" 감상 칸 (🎤 말로 적기 지원)
   - **키워드 버튼**(색이 고와요, 가족이 생각나요 …): 누르면 그 문장이 감상 칸에 들어가고, 다시 누르면 빠짐
   - **✨ AI로 다듬기**: 고른 키워드와 메모를 자연스러운 2~3문장으로 완성 (`되돌리기`로 원래 글 복원)
   - AI 도슨트에게 물어본 질문·답변도 그 작품 노트에 자동으로 모입니다. (안내 문구·오류는 빼고)
2. **첫 화면 작품 목록 맨 아래**: `📒 내 관람 노트` 바로가기 (모은 작품 수 표시)
3. **노트 화면 `note.html`**: 모은 작품 카드(별표·메모 수정, 물어본 것 보기)
   - **AI가 자동으로 감상문을 다듬음**: 노트를 열 때, 별표를 바꾸거나 감상을 고칠 때 (내용이 그대로면 저장해 둔 글을 다시 씀)
   - 다듬은 글은 직접 고칠 수 있고, `↻ 다시 다듬기`로 새로 쓸 수 있음
   - `📤 공유하기` → 휴대폰 공유 창(메모·카카오톡 등). 공유 창이 없는 PC에서는 글을 복사
   - 공유 창은 버튼을 누른 순간에만 열 수 있어서, 공유 전에 감상문을 미리 다듬어 둠

## 파일

| 파일 | 내용 |
|---|---|
| `public/note.html` | 노트 화면 |
| `public/js/note.js` | 노트 저장, 설명 화면 버튼, 첫 화면 바로가기, 노트 화면 동작 |
| `public/css/note.css` | 노트 디자인 (색·글꼴은 `style.css` 변수 사용) |
| `api/review.js` | 감상문 API `POST /api/review` (노트 전체 감상문 / `mode: "memo"`는 감상 한 줄 다듬기) |
| `public/index.html`, `public/exhibit.html` | `<script src="js/note.js">` 한 줄씩만 추가 |

화면(`exhibit.js`, `home.js`, `style.css`)과 AI 도슨트(`api/docent.js`, `api/_lib/*`) 코드는 고치지 않았습니다.

## 개인정보

- 별표·메모·질문은 **관람객 기기(브라우저 localStorage)에만** 저장됩니다. 서버에 저장하지 않습니다.
- `감상문 만들기`를 누를 때만 노트 내용이 `/api/review`로 가고, 서버는 내용을 저장하거나 기록하지 않습니다.
- 브라우저 기록을 지우면 노트도 지워집니다.

## AI 감상문

- AI 도슨트와 같은 `GROQ_API_KEY`를 씁니다. (모델: `GROQ_MODEL`, 기본 `openai/gpt-oss-120b`)
- 키가 없으면 AI 없이 "인상 깊었던 작품은 ○○예요. (작품 소개) 제 감상은 이래요. (메모)" 형식으로 정리합니다.
- 규칙: 관람객이 쓰지 않은 감정·추억은 지어내지 않고, 작품 사실은 `exhibits.json` 설명과 물어본 내용만 씁니다.
- 한 번에 작품 10개, 1분에 10번까지 (AI 사용료 보호)
- 키워드 문장은 `public/js/note.js` 맨 위 `MEMO_KEYWORDS`에서 바꿀 수 있습니다.
